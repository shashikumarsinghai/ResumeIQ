# 📄 ResumeIQ

> **Resume Analyzer, ATS Score Calculator & Career Recommendation System**

ResumeIQ is a Streamlit-based web application that analyzes resumes, calculates an ATS score, extracts technical skills, recommends job roles, suggests learning resources, generates resume feedback, and allows users to download a professional PDF report.

---

## 🚀 Features

- 📄 Upload Resume (PDF)
- 🧠 Automatic Skill Extraction
- 📊 ATS Resume Score
- 💼 AI Job Recommendations
- 📚 Course Recommendations
- 📋 Resume Feedback
- 📈 Skills Analysis Chart
- 📄 Download Professional PDF Report
- 🎨 Clean & Interactive Streamlit UI

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/shashikumarsinghai/ResumeIQ.git
```

Go to the project directory

```bash
cd ResumeIQ
```

Create a virtual environment

```bash
python -m venv .venv
```

Activate the virtual environment

### Windows

```bash
.venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
